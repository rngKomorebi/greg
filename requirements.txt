# Capped below each dependency's next major version, where APIs get removed,
# rather than pinned: one pin cannot serve every supported Python (3.10-3.14).
# The lower bounds are the oldest versions the code needs.
#
# matplotlib is the exception and stays pinned exactly. The Spectrometer
# Analysis page unpickles figures made by daplis with matplotlib 3.10.8, and
# pickled figures do not survive a matplotlib upgrade: under 3.11, plots A and
# E fail on them. matplotlib 3.10 has no wheels for Python 3.15, which is why
# 3.15 is not supported. Change this pin only together with daplis.
streamlit>=1.56,<2
numpy>=1.24,<3
matplotlib==3.10.8
scipy>=1.10,<2
pandas>=1.4,<4
pillow>=7.1,<14
